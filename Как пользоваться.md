# Режим правок. Как пользоваться

Режим правок включается на любой HTML-странице: сайте, презентации, своём файле. На странице можно двигать фото и блоки, править текст и оставлять замечания, а потом отдать всё ИИ одним сообщением или скачать готовый файл с правками. Сама страница не меняется, правки хранятся в браузере, а в файлы их вносит ИИ или кнопка «Скачать с правками»

## Что внутри

- `index.html` стартовая страница пакета: «Открыть папку», фраза для агента, кнопка-закладка
- `open.js` и `sw.js` открывают вашу папку прямо на сайте пакета, уже в режиме правок
- `Пример.html` страница, чтобы попробовать. Режим в ней включён всегда, достаточно открыть её двойным щелчком или кнопкой «Попробовать на примере» на сайте пакета
- `pravki.js` сам режим
- `pravki_server.py` маленький сервер для агента: открывает папку сайта в браузере уже с режимом
- `locate.py` помощник для агента: по пакету правок находит файл и строку каждой записи
- `Инструкция для ИИ.md` первое сообщение в чат или `CLAUDE.md` и `AGENTS.md` для агента

## Включить режим

Режим работает в браузере на компьютере. Способы ниже в том же порядке, что на сайте пакета

### Открыть папку здесь

Для своих файлов, если работаете с ИИ в чате. Ничего не нужно ставить

1. Откройте https://tomb-raider.github.io/rezhim-pravok/ и нажмите «Открыть папку». Выберите папку с презентацией или сайтом. Можно и один HTML-файл, но тогда не будет видно картинок
2. Страница откроется в этой же вкладке уже в режиме правок. Если в папке несколько страниц, сначала появится их список
3. Когда закончите, нажмите «Скопировать правки» и отправьте в чат «Инструкцию для ИИ», правки и файлы страниц из правок вместе с файлами стилей (.css). ИИ пришлёт исправленные файлы. Без ИИ нажмите «Скачать с правками» и замените старый файл скачанным

Chrome при выборе папки спросит, загрузить ли файлы на сайт. Это его обычный вопрос: файлы не уходят в интернет, сайт кладёт их в хранилище вашего браузера. Чтобы вопроса не было, перетащите папку прямо на страницу. Правки тоже хранятся в браузере. Если файлы поменялись, откройте папку заново

### Попросить агента

Для Claude Code, Codex, Cursor, GigaCode и других агентов, которые работают с файлами

1. Отправьте агенту из папки с презентацией фразу с сайта пакета: «Включи режим правок для этой папки. Возьми его с github.com/Tomb-Raider/rezhim-pravok и сделай всё по его «Инструкции для ИИ». Правки, которые я потом пришлю, вноси по ней же»
2. Агент скачает пакет, запустит `pravki_server.py`, и страница откроется в браузере уже с режимом
3. Когда закончите, вставьте агенту правки, и он сам внесёт их в файлы

Нужен Python 3. На Mac при первом запуске система может предложить поставить инструменты разработчика, согласитесь. На Windows Python ставят с python.org, в установщике отметьте «Add python.exe to PATH». Плюсы этого способа: режим не попадает в файлы сайта, в правках будет точная папка, а многостраничный сайт листается списком в панели

### Закладка для сайтов

Подходит для Chrome, Яндекс Браузера и Edge на Mac и Windows, для Safari на Mac

1. Откройте сайт пакета https://tomb-raider.github.io/rezhim-pravok/ и перетащите кнопку «Режим правок» на панель закладок. Если панели не видно, включите её: Cmd + Shift + B на Mac, Ctrl + Shift + B на Windows
2. Откройте свою страницу: сайт, презентацию или HTML-файл двойным щелчком
3. Нажмите закладку. Внизу появится панель «Режим правок»

Закладка подгружает режим с сайта пакета, поэтому нужен интернет. Сам режим ничего не отправляет в сеть, правки остаются в браузере. Закладка каждый раз берёт свежую версию режима, поэтому на рабочих страницах надёжнее включать его через агента или строкой в странице

Некоторые большие сайты своей защитой не пускают закладку. Если файлы такого сайта есть у вас, включите режим через агента

### Строкой в странице

Для своих HTML-файлов. Положите `pravki.js` рядом со страницей, добавьте перед `</body>` строку

```html
<script src="pravki.js" defer></script>
```

и откройте страницу с `?pravki` в конце адреса. Без `?pravki` режим не включается. Перед выкладкой сайта строку и `pravki.js` уберите, чтобы режим не уехал вместе с сайтом

## Что делать на странице

- **Двигать.** Тяните мышью фото, блок или текст. Края прилипают к соседям, видна розовая линия. Всё внутри карточки тянет карточку целиком. Фото внутри карточки выбирает двойной щелчок. Текст внутри карточки двойной щелчок открывает для правки, а после Esc он выбран и тянется отдельно. С Cmd, на Windows с Ctrl, привязка отключается, с Shift берётся блок уровнем выше. Стрелки двигают выбранное на 1 px, с Shift на 10
- **Размер.** Тяните квадратик в правом нижнем углу выбранного. Фото держит пропорции, у текста меняется ширина
- **Текст.** Двойной щелчок, правьте прямо на странице. Esc заканчивает. Ctrl + Shift + пробел ставит неразрывный пробел, на Mac можно и Alt + пробел, Enter переносит строку
- **Замечание.** Alt + щелчок по чему угодно, справа откроется список, напишите, что не так. С Shift берётся блок уровнем выше
- **Назад и вперёд.** Стрелки на панели или Cmd + Z и Shift + Cmd + Z. На Windows Ctrl вместо Cmd
- **Сетка.** Кнопка показывает сетку и открывает меню: клетка или колонки, ползунками шаг клетки, число колонок и промежуток. Пока сетка видна, края встают по ней. «Скрыть сетку» убирает её. Выбор браузер помнит, свою сетку по умолчанию агент может задать в настройках
- **Телефон.** Страница с правками шириной 390 px, как на телефоне. Сдвиги здесь такие же, как на широком экране: если что-то уехало, напишите ИИ, как должно быть на телефоне. Если страница открыта файлом и режим включён закладкой, здесь снимок страницы без её скриптов
- **Убрать блок.** Выберите блок щелчком и нажмите Delete. Он станет бледным с красным пунктиром, в правках появится «удалить: блок целиком». Delete ещё раз или Cmd + Z вернёт его
- **Список.** Все правки страницы. Лишнюю убирает крестик, к любой можно дописать замечание. «Сбросить» убирает правки этой страницы, а если на ней правок нет, то все, перед этим спрашивает поверх списка. Знак вопроса в шапке списка показывает все клавиши

- **Панель.** Стоит внизу по центру. Тяните её за название, чтобы переставить, двойной щелчок по названию вернёт её на место
- **Глаз.** Прячет сам режим: рамки, подсветку и панель. Правки остаются на странице, видно, как она будет выглядеть. Ссылки открываются, кнопки нажимаются, можно перейти на другую страницу, там режим тоже будет скрыт. «Назад» и «Вперёд» работают. Внизу остаётся маленькая капсула «Режим правок скрыт», щелчок по ней возвращает режим. Если режим включали закладкой, на другой странице включите его снова закладкой

Ссылки и кнопки в режиме правок не нажимаются, чтобы в них можно было править текст. Нажать по-настоящему можно щелчком с Cmd, на Windows с Ctrl

## Скачать с правками, без ИИ

Нажмите «Скачать с правками» на панели. Скачается та же страница, где уже стоят ваши сдвиги, размеры, новый текст и убранные блоки. Замените ею старый файл. Если правили несколько страниц, скачается архив, страницы в нём лежат по тем же папкам

Режим правит сам файл страницы, а не то, что видно на экране, поэтому в файл не попадает ни сам режим, ни то, что дорисовали скрипты страницы. Сдвиг записывается в блок так, что соседние блоки остаются на местах, как в режиме. Если блок дорисовал скрипт и в файле его нет, такую правку режим записать не может, он скажет об этом, её отдайте ИИ

Замечания словами в файл не попадают. Откройте новый файл в режиме правок, внесённое уйдёт из списка, и останутся только замечания для ИИ

Кнопка работает, когда страница открыта через «Открыть папку», агентом или с сайта. Если страница открыта файлом прямо с диска, браузер не даёт режиму прочитать её, и режим попросит выбрать этот же файл ещё раз

## Отдать правки ИИ

Нажмите «Скопировать правки». Текст начнётся со слов «ПРАВКИ САЙТА». Если браузер не дал скопировать сам, режим покажет текст выделенным, нажмите Cmd + C или Ctrl + C. Можно и «Скачать файлом» в списке

### В чате: ChatGPT, GigaChat, Claude

1. Первым сообщением отправьте «Инструкцию для ИИ» целиком
2. Вторым вставьте правки и приложите файлы страниц из строк «═══» вместе с файлами стилей (.css), если стили лежат отдельно
3. ИИ пришлёт исправленные файлы целиком. Сохраните их вместо старых и откройте страницу снова

Внесённые правки режим уберёт из списка сам, когда увидит их на странице

### Агенту в папке: Claude Code, Codex, Cursor, GigaCode

Положите копию «Инструкции для ИИ» рядом с сайтом под именем `CLAUDE.md` для Claude Code или `AGENTS.md` для остальных, или просто попросите агента её прочитать. Если такой файл уже есть, допишите инструкцию в его конец. Потом вставьте правки в чат с агентом. Он найдёт каждое место в файлах и внесёт

## Как читать сдвиги

Сдвиг записывается в пикселях самого блока: «сдвиг: вправо на 24, вниз на 120». Если страница вписана в окно, как слайд, это пиксели слайда, а не экрана. Строка «выровнено» говорит, к чему блок прилип: «левый край по левому краю «Заголовок»». ИИ выравнивает по ней, а не только по числам. «По клетке 8 px сетки режима» и «по колонке 3 из 12 сетки режима» значат сетку, которую показывал режим, а не сетку сайта

Сайт перестраивается под ширину окна, поэтому в сдвиге записана и ширина окна, на которой двигали. После правки откройте «Телефон» и проверьте, что всё на месте

## Где хранятся правки

В браузере, отдельно для каждой страницы. Можно закрыть страницу и вернуться, правки останутся. В другом браузере или на другом компьютере их не будет. Чтобы отдать правки коллеге, скопируйте их текстом
