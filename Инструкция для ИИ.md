# Режим правок. Инструкция для ИИ

Для человека. В чате (ChatGPT, GigaChat, Claude) отправьте этот файл целиком первым сообщением, вторым HTML-файл страницы и правки. Агенту в папке (Claude Code, Codex, Cursor, GigaCode) положите копию рядом с сайтом под именем `CLAUDE.md` или `AGENTS.md`, а если такой файл уже есть, допишите эту инструкцию в его конец

---

## Задача

Человек отметил правки прямо на HTML-странице в режиме правок и прислал их одним текстом, который начинается с «ПРАВКИ САЙТА». Твоя работа внести каждую запись в исходные файлы точно по адресу. Ничего, о чём не просили, не меняй: ни текст, ни стили, ни разметку вокруг

## Формат пакета

```
ПРАВКИ САЙТА · <сайт> · <дата время> · записей: N
папка: <путь к папке сайта>          (или «адрес: <адрес страницы>», если папка неизвестна)

═══ <страница.html>  ·  <заголовок страницы>
    собирается: <скрипт>              (если страница собирается скриптом)

[1] <адрес>  · <файл-источник>         (метка, если текст живёт не в разметке)
- было
+ стало
! замечание

[2] <адрес>  · блок целиком, не текст
  <описание блока: текст через « / » или тег, класс, файл картинки>
  где: #section > div.card:nth-child(3)
  сдвиг: вправо на 24, вниз на 120 · окно 1440 px
  размер: 640 × 360 → 720 × 405         (или «ширина 640 → 720», «высота 360 → 405»)
  выровнено: левый край по левому краю «Заголовок…», верх по шагу сетки 8
! замечание
```

- `[N]` и адрес после него служебные: по ним отвечают человеку, в файлах их нет. Нумерация сквозная по всем страницам
- `-` и `+` текст до и после правки. `&nbsp;` значит неразрывный пробел, `<br>` перенос строки
- `!` замечание человека, его нужно выполнить
- строка без знака в начале описывает блок, к которому оставлено замечание или который сдвинули
- `где:` короткий путь к блоку в разметке: от ближайшего `id`, с классами
- `сдвиг`, `размер`, `выровнено` бывают и у текстовых записей, тогда они идут после `-` и `+`
- пометка «на странице не нашёлся» значит, что блок исчез или сменил текст после того, как его отметили

## Как вносить

1. **Найди место.** Текст ищи по строке «было» или по описанию блока, без учёта тегов и неразрывных пробелов. Картинку ищи по имени файла из описания. Если есть «где» с `id`, начни с него. Если у записи или страницы есть метка источника или «собирается», правь тот файл, а страницу пересобери тем же скриптом. Собранный HTML руками не правь, следующая сборка всё затрёт
2. **Текст.** Замени «было» на «стало», сохрани разметку вокруг: теги, классы, ссылки. Неразрывный пробел ставь так, как принято в файле: в HTML `&nbsp;`, в строке JavaScript `\u00a0` или сам символ. Перенос `<br>` ставь только там, где он есть в «стало»
3. **Сдвиг и размер.** Числа в пикселях самого блока. Если страница вписана в окно через `scale`, как слайд, это пиксели слайда, а не экрана. Вноси так, как устроена вёрстка
   - блок стоит абсолютно (`position: absolute`, `left`, `top`): поправь координаты и ширину
   - блок в потоке (flex, grid, обычные блоки): поменяй отступ, порядок, колонку или ширину так, чтобы блок встал туда же
   - строка «выровнено» важнее чисел: если блок прилип к краю соседа, выровняй по этому краю, а не по пикселям
   - «по колонке N из M сетки режима» и «по шагу сетки режима» относятся к сетке, которую показывал режим (по умолчанию 12 колонок по ширине ближайшего широкого блока), а не к сетке сайта. Если у сайта своя сетка, выравнивай по ней
   - «окно N px» в первой строке сдвига или размера это ширина окна, на которой двигали. Если сайт перестраивается под ширину, не ломай другие ширины: правь в нужном `@media` или выбирай способ, который работает на всех
   - `transform: translate` ставь, только если иначе никак
4. **Замечание.** Сделай, что просит. Если его можно понять двумя способами и это вопрос вкуса или смысла, не угадывай, а спроси одним коротким вопросом. Остальное делай сразу
5. **Не нашлось.** Если места нет, не придумывай. Перечисли такие записи в ответе

## Как ответить

- В чате: пришли каждый изменённый файл целиком, одним блоком кода на файл. Без «остальное без изменений» и без многоточий вместо кода. Если файл не помещается в один ответ, скажи, что продолжение будет в следующем сообщении, и не обрывай посередине тега
- Агентом: правь файлы на месте
- В конце коротко по номерам записей: что сделано, что не нашлось, какой вопрос остался

## Если ты агент в папке

Пакет «Режим правок» лежит у человека в папке. Найди в нём `pravki_server.py`, `pravki.js` и `locate.py`

**Включить режим на сайте.** Запусти сервер в фоне и дай человеку адрес из первых строк вывода

```
python3 <пакет>/pravki_server.py "<папка сайта>" --open
```

На Windows `python` вместо `python3`. Сервер раздаёт папку и на лету дописывает режим в каждую страницу, файлы сайта не меняются. Порт у каждой папки свой и постоянный, поэтому правки в браузере не теряются между запусками. Не копируй `pravki.js` в папку сайта и не дописывай `<script>` в её страницы, если человек не просил

**Найти места правок.** Сохрани пакет в файл и запусти

```
python3 <пакет>/locate.py правки.txt
```

Он печатает файл и строку каждой записи с пометкой «точно», «по началу», «по концу» или «по файлу». Ничего не меняет. Если в пакете нет строки «папка», добавь `--root <папка сайта>`

**Прочитать правки со страницы самому.** Если у тебя есть доступ к браузеру, где открыта страница: `window.__pravki.text()` вернёт пакет, `window.__pravki.clear()` очистит список после того, как всё внесено

**Настройки сайта.** Если текст собирается скриптами, есть анимации появления или служебные подписи, положи в корень сайта скрытый файл `.pravki.json`

```json
{
  "name": "Название для шапки правок",
  "start": "index.html",
  "pages": { "about.html": { "name": "О нас", "src": "build.py", "sources": { "#team": "team.js" } } },
  "sources": { "#faq": "faq.js" },
  "skip": [".counter", ".ticker"],
  "freeze": true,
  "reveal": true,
  "css": ".accordion .body{height:auto!important}",
  "grid": { "cols": 12, "gutter": 24, "row": 8, "frame": ".container" }
}
```

- `src` страница собирается этим скриптом, правки идут в него
- `sources` текст этих блоков живёт в другом файле
- `skip` служебные блоки: их не правят и не двигают
- `freeze` остановить анимации GSAP, ScrollTrigger и Lenis
- `reveal` сразу показать всё, что спрятано до прокрутки
- `css` свои стили на время правки
- `grid` сетка для кнопки «Сетка»: колонки, промежуток, шаг строк и блок-кадр, по которому она строится

После правок перезагрузи страницу. Текст и сдвиги, которые уже стоят в файлах, режим убирает из списка сам
